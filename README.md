### ML projects

**[Bias-in-Bios](https://github.com/kkamph26/Bias-in-Bios)**

A CBS project on gender bias in machine learning, done in Google Colab. Using the public Bias in Bios dataset of short online biographies, we predict a person's occupation from the text and test whether men and women are treated differently. We compare a simple bag-of-words model with an LLM and look at accuracy, true-positive rate by gender, and what balancing the data does.

**[Machine-Learning](https://github.com/MLJonstrup/Machine-Learning)**

A group project on predicting whether a road traffic accident is severe. It uses about 100,000 records from 2023 and compares logistic regression, decision tree, random forest and k-nearest neighbors in scikit-learn. Because severe accidents are rare, the models are judged on recall and PR-AUC instead of plain accuracy. Made for the Applied Machine Learning course at CBS in 2025.

### Mobile project

**[MentorZone](https://github.com/kkamph26/MentorZone)** (original repository by [shadi77777](https://github.com/shadi77777/MentorZone))

A mobile app where users find and book sports trainers. Built with React Native, Expo and Firebase. Users sign up, pick a sport, compare trainers by price, experience and rating, leave comments, chat with the trainer and book a time in a calendar. Booked times disappear for other users. Anyone can also register as a trainer, and there is an AI support chat.

### Web apps

**[JoeForum](https://github.com/MLJonstrup/JoeForum)** (original repository by [MLJonstrup](https://github.com/MLJonstrup))

A group project for a CBS course where we built a forum as a complete web application. It has a Node.js and Express server, an SQLite database, sign-up and login with hashed passwords, and confirmation messages sent by email and SMS. We also put it online on a cloud server with its own domain, so it ran as a real website and not only on our own computers. It showed us the whole path from writing the code to running it live.

**[Medicin](https://github.com/shadi77777/Medicin)** (original repository by [shadi77777](https://github.com/shadi77777))

A group project that is a web prototype called Medicin Spild Rapport (Medicine Waste Report), made for a hospital pharmacy setting. You pick a hospital, a department and a section, and the page shows for each medicine how much was bought, used, discarded and kept in stock. From this it works out how much was wasted and what the waste cost in DKK. It is built with plain HTML, CSS and JavaScript and uses sample data.
